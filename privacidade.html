Política de Privacidade

Última atualização: 27 de setembro de 2026

Esta política descreve como a Kiwami ("Kiwami", "nós"), operadora da plataforma Kota Analytics, coleta, usa e protege dados ao prestar serviços de análise de dados de marketing e dashboards de mídia paga para seus clientes (agências e anunciantes).

Quem somos e o que fazemos

A Kiwami é uma agência de dados que opera a Kota Analytics, um painel de indicadores (dashboard) que consolida métricas de campanhas de mídia paga (Meta Ads, Google Ads, Display & Video 360, LinkedIn Ads) e de comportamento de site (Google Analytics 4) em relatórios para nossos clientes.

Quais dados coletamos

  • Dados de campanha e conta de anúncios: investimento, impressões, cliques, conversões, nome de campanha/grupo/anúncio e metadados de criativos, obtidos via API das plataformas de mídia com autorização do cliente titular da conta.
  • Dados de analytics do site do cliente: sessões, usuários, origem de tráfego e eventos de conversão via Google Analytics 4, sem dados que identifiquem pessoalmente o visitante do site do cliente.
  • Dados de cadastro: nome, e-mail e informações de contato de quem acessa o painel administrativo ou o dashboard publicado.

Não coletamos nem processamos dados sensíveis (saúde, origem racial, orientação sexual, dados de crianças) como parte do serviço.

Para que usamos os dados

  • Consolidar e exibir métricas de desempenho de campanha nos dashboards contratados pelo cliente;
  • Gerar alertas automáticos sobre custo por lead, taxa de conversão e outros indicadores definidos com o cliente;
  • Diagnosticar falhas de sincronização e manter a integridade dos dados coletados.

Os dados de campanha e de site são usados exclusivamente para prestar o serviço contratado — não vendemos, alugamos nem compartilhamos esses dados com terceiros para fins de publicidade ou qualquer outra finalidade fora do escopo do serviço.

Uso de APIs do Google

O uso e a transferência, pela Kota Analytics, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use). Os dados obtidos via Google Ads API e Google Analytics Data API são usados apenas para exibir métricas ao cliente titular da conta autorizada, nunca para treinar modelos de IA de uso geral nem repassados a terceiros não autorizados.

Armazenamento e segurança

Os dados são armazenados em banco de dados hospedado no Brasil (região São Paulo), com acesso restrito por autenticação e controlado por papéis (administrador da agência vs. visualização do dashboard do cliente, protegida por senha). Cada dashboard publicado é acessível apenas com a senha definida para aquele cliente.

Retenção

Mantemos os dados de campanha e analytics pelo período do contrato com o cliente, e por um prazo razoável após o encerramento para fins de encerramento de conta e obrigações legais, após o qual os dados são removidos.
